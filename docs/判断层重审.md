# 分析师判断层 · 定时重审方案

## 约束
- 维护者走 Claude 会员订阅，无 API 额度 → 不能放进 GitHub Actions。
- 用本机 Claude Code 定时任务（桌面端「定时任务」）起草，草稿只落本地，**维护者说「发」才 commit + push**（push 触发 Cloudflare 发布，属对外操作）。

## 触发
| 时机 | 内容 |
|---|---|
| 到期日次日（下一次：2026-11-05，对应 11-04 到期的两条） | 只重审到期条目 |
| 每月第一个周日 10:00（周日 06:30 管线跑完之后） | 全部 analyst_calls 体检：到期、证伪条件是否已触发、依据是否仍在账本 |

```

   处理方式三选一并写明理由：续期（新 review_by + 补新依据）/ 改写（保留七件套结构）/ 作废（written 加「已作废」并说明证伪事实）。
```
