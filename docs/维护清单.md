# 数据维护清单（内部底账，不上站）

自动项随每周日 06:30 管线刷新；人工项事件驱动、最长月度。过周期未更新的板块，结论视为过期——宁可标「过期待更」也不用旧结论装新判断。

| 数据块 | 更新方式 | 周期 | 所在页 |
|---|---|---|---|
| 行情 / SEC Form4 / 发射 / 招聘 / FEC / 新闻 | 自动（update.py） | 每周日 06:30 | 全站账本 |
| 供需剪刀差状态（scissors） | 人工判定 | 事件即时（翻转触发周报头条） · 最长月度 | 物理供需 |
| 产品解剖（teardowns） | 人工 | 最长月度 | 物理供需 |
| 8 层供应链灯色与适用期（supply） | 人工 | 事件即时 · 最长月度 | 先行引擎 |
| 先行信号人工项（H-1B / 专利 / 政治接触面） | 人工 | 事件驱动 · 最长月度 | 先行引擎 |
| 技术树六线 / TRL（techtree） | 人工 | 月度深核 | 技术树 |
| 政治状态机 / 资本存量与负债表 | 人工 | 事件即时 | 政治地缘 |
| 实体与连带谱（entities / edges） | 人工 | 事件即时 | 关系图谱 |
| 人物框架与人物卡 | 人工（动态自动挂） | 事件驱动（动态每周自动） | 人物网络 |
| 估值锚与溢价（valuation） | 人工 | 财报后 48h 强制 | 市场资本 |
| 倒计时（countdowns） | 人工 | 事件落地即换 | 全站侧栏 |
| 分析师判断层（analyst_calls） | AI 生成 + 人工复核 | 滚动复核 · 到期强制重审 | 首页 |

## 发布前注意
- 对外转发截图或研报前，删除原始行情数值（规避数据源转发授权）；观点、判定与自制图表可自由发布。

## C 级归档
- C 级（单源未交叉）由 update.py 写入 `archive/ledger_c.jsonl`，只追加、不发布；`data.js` 只存 A/B，`meta.c_archive_count` 记录归档条数。
- 降噪规则见 update.py 头注 R7：白名单媒体、马斯克系相关性、繁简归一去重、每轮上限。
